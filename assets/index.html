Audio & MIDI connections

MIDI IN → step entry / clock → sequencer → MIDI OUT → synth or drum machine.

Audio IN → selected tape recording. Tape heads → playback amplifiers → audio gates → mix → Audio OUT. Both tapes keep moving when gated.

Proposed rear panel: four 3.5 mm sockets, MIDI IN / OUT (TRS Type A) and mono AUDIO IN / OUT. Allow an 18 × 8 × 12.3 mm jack body, 16 mm spacing and 22 mm clearance behind the panel per socket. Panel strip: 80 × 18 mm minimum; plug and case clearance still need checking.

The two codec inputs switch between line input while recording and head returns while playing. Tape gates need a separate analog circuit after playback; MIDI sockets need the proper input isolator and output driver. This is a wiring proposal, not a measured Panasonic PCB fit.

Details

Click either cassette or its LEFT / RIGHT button to select a deck. The front REC / PLAY / STOP keys, audio input and tape controls apply to that deck. Play both / Stop both operate both decks. R: Record · S: Stop · Space: Play.

The 16 LEDs show the selected track: dim red marks enabled steps; bright red marks the playing step. The outlined bench step is the edit cursor. The bench editor is a virtual tool; the lid module only contains LEDs. Expand LED module below the machine for the PCB footprint and depth drawing.

Recording replaces tape audio. Files stop recording when they finish; Repeat input keeps them running. Short clips leave silence in the rest of the loop. Use headphones with the microphone.

Runs the AnsaLoop ARM firmware in Virtual Daisy, using a fast linear tape model. The separate circuit lab runs ngspice. Panasonic electrical parameters are not measured yet.

One ARM firmware image controls both virtual transports and the sequencer. GPIO contacts control REC / PLAY / STOP / CUE. MIDI uses the emulated 31,250-baud UART. The virtual MIDI synth is an external test receiver. The front selector is provisionally left tape / SEQ / right tape; side switches and spare LED remain unassigned. Independent physical operation of the Panasonic mechanisms is not verified yet.
